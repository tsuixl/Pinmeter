- 2026-10-04 产品优化范围：网络控制与故障恢复列为独立待处理问题，用户明确排除本轮修改。VPN 断联报告仍未定位，现有恢复与验收待办保留；本轮不修改控制实现、不启停真实规则、不执行网络故障注入。
