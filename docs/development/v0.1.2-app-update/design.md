# app-update

> 当前工作版本：v0.1.3

## 目标与范围

- Windows 安装版提供检查、下载、签名校验、用户确认安装及重新启动；便携版可检查和阅读公告，使用完整发行包手动升级。不自动发布、推送或强制重启。
- 参考本地 Cindy `f119bde0d` 的轻提示、安装前公告预览、升级后一次告知和历史查看；沿用 Pinmeter 的共享核心、MVVM 和唯一后端状态，不移植 Electron 更新服务或文件覆盖更新器。
- 自动检查默认开启，启动延迟检查并限制为每天一次；手动检查不受周期限制。下载、安装均由用户发起。后台错误保持安静，不唤起托盘中的主窗口。

## 方案

- 2026-10-04 v0.1.3 预览分发：本次发布安装器、Tauri 签名、版本公告和同版本 `latest.json`，作为可核对的发行材料；GitHub Release 保留 prerelease 标志，不推进 `/releases/latest` 稳定入口。用户从版本发布页手动下载安装/完整便携包；预览自动更新通道仍未就绪，v0.1.1 没有更新客户端，不能声称其可自动升级。保持现有信任公钥和更新配置，不为本次预览改用任意动态下载源。

- 2026-10-04 发行可靠性：校验签名与版本绑定、清单异常、平台包缺失和网络失败分别提供真实原因，不把材料错误统一提示为网络故障。生成清单前要求安装器名称、实际 PE 产品版本和签名内版本（存在时）与目标版本一致，先验证再写入材料，拒绝合法旧包被误标新版。稳定版仍使用现有固定官方更新入口；预览通道在具备实际清单发布入口前保持明确未就绪，不自动发布、不静默改到任意发行。实际 A→B 安装与自启路径验收单独记录，不改网络清理实现或执行真实规则操作。

- UI 入口为侧栏提示、设置中的版本与更新、托盘检查更新。使用 [Sakani Modal](https://main--6a5a658b3681fcc010430db5.chromatic.com/?path=/docs/application-modal--docs)、[Toast](https://main--6a5a658b3681fcc010430db5.chromatic.com/?path=/docs/composite-toast--docs)、[Progress](https://main--6a5a658b3681fcc010430db5.chromatic.com/?path=/docs/core-progress--docs) 与已有 Card/Button，依赖 `@sakaniui/react` 0.3.1。HTML 预览仅供布局；深浅主题、焦点、禁用、加载和错误分别截图验收。
- 公告组件复用安装前、升级后及历史模式；正文按版本展示新增、优化、修复，长内容滚动。预览不推进安装后已读游标；实际阅读并关闭才确认已读；应用不可见或正在退出时不弹窗。当前及已有公告随包内置；远端目标版本的公告缺失时明确说明，不冒用其他版本内容。
- `core/updates` 管理状态转换、偏好、公告及检查周期；`platform/updates` 负责原子持久化、安装形态识别和系统能力；`host/updates` 封装 Tauri updater、命令、后台检查与事件；`frontend/features/updates` 负责 View/ViewModel，客户端适配在 `shared/client`。DTO 沿用受控导出，不在 View 直接调用 Tauri。
- 状态为待机、检查、发现新版、下载、就绪、安装准备、失败；下载目标固定，重复操作被拒绝。新结果用递增修订号接纳，切页/重连不重建下载或覆盖较新状态。下载失败保留目标供重试，校验失败不能安装。
- 安装前共用现有退出准备：等待已接纳的设置操作，按 `release_network_on_exit` 处理规则，必要时确认保留禁用；确认后停止辅助进程，再交给安装器。准备失败中止安装，安装器启动失败恢复监控并保留真实规则状态。不把“关闭至托盘”当作退出。
- 使用 Tauri 2 更新插件和 NSIS 签名安装包，固定可信 HTTPS 更新入口；不接受前端传入下载地址或密钥。生产私钥仅保存在本机仓库之外，公钥随配置提交。公共入口采用 GitHub Release 的 `latest.json`，正式发布时须先上传并核对包、签名和公告，再使清单可见；未发布清单明确报告，不能宣称线上链路已验收。预览发行须显式选择更新分发策略，不把 GitHub 的 latest 当作预览通道。
- 新增工具从同版本完整安装包和公告生成待发布清单，输出至忽略的构建目录；开发及受管 `testN` 包禁止在线安装。第一版不提供增量更新、空闲自动重启、便携包自动覆盖和自动回滚承诺。
- 当前 v0.1.1 尚无更新客户端，需手动安装一次本版本后才能在线更新。

- 首期已下载包仅在本次进程中保持就绪；退出后重新检查和下载，界面明确说明。不以落盘缓存存在作为签名校验凭据：官方插件完成签名验证后保存 SHA-256 到内存，安装前重新核对同一文件，缓存被替换则拒绝安装。

## 验收

- 无新版、离线、清单异常、公告缺失、下载中断、签名失败及重复点击有准确状态；未知总大小不伪造百分比，下载完成与安装成功文案分开。
- 设置/侧栏/托盘复用一个状态，隐藏窗口不抢焦点；公告预览、已读、跨版本和手动历史互不干扰，保存失败可重试。
- 实际 A→B 安装验证配置、自启、主程序与全部 helper 资源，覆盖有/无网络限制及清理失败。不能以生成安装包代替真实安装验证。
- 通过相关核心/宿主/前端/工具检查，按项目入口构建并核对完整 Windows release；线上未发布、管理员、系统重启或长期场景的缺口分别记录。
