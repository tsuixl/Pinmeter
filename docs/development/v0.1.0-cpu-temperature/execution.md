## 进度

- Windows 宿主启动统一请求权限，温度辅助程序继承权限；缺驱动、权限不足、超时、失败与不支持独立呈现。有效温度复用五分钟历史，无效区间断开。
- 既有传感器选择、安装器校验、已有驱动幂等、温度历史和前端异常状态检查通过；已有驱动的 Windows 实机曾取得连续温度读数。模拟安装检查不等于干净电脑安装通过。
- 使用现有 Sakani 卡片、图表、按钮和提示组件，HTML 仅作布局参考；完整原生 DPI、其他平台温度与发行验收未完成。安装器条款及对应源码待办见 [desktop-runtime](../v0.1.0-desktop-runtime/execution.md)。
